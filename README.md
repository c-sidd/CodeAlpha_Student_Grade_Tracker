# Student Grade Tracker

A console-based Java application developed for the CodeAlpha Java Programming Internship.
This project helps manage student records, calculate grades, percentages, and store data using file handling.

---

# 🚀 Features

* Add student details
* Store marks for 3 subjects
* Calculate:

  * Total Marks
  * Percentage
  * Grade
* Display all student records
* Search student by name
* Save records to a text file
* Menu-driven console interface
* Uses OOP concepts and ArrayList

---

# 🛠️ Technologies Used

* Java
* OOP (Object-Oriented Programming)
* ArrayList
* File Handling
* Scanner Class

---

| Percentage   | Grade |
| ------------ | ----- |
